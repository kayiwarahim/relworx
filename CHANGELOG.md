# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/).

## Unreleased

### Added
- Expanded package documentation and Laravel webhook-listener example.
- Added bug-report and feature-request issue forms.

- Added dependency review for pull requests.
- Added security, contribution and release-maintenance guidance.

## [1.0.0] - 2026-11-09

### Added
- Laravel integration for Relworx mobile-money collections and disbursements.
- Wallet balance and transaction-history/status services.
- Configurable HTTP client, timeout handling and package exceptions.
- Webhook route, signature verification and Laravel webhook events.
- Laravel package auto-discovery and publishable configuration.
- Automated test workflow for supported PHP and Laravel/Testbench combinations.
